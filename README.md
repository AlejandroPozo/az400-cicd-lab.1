# Laboratorio colaborativo de CI/CD

## Objetivo
Este laboratorio crea la base de un sitio web estatico donde siete estudiantes trabajan de forma colaborativa. Cada estudiante actualiza su componente desde una rama independiente y envia un pull request para validacion e integracion.

## Estructura del proyecto
- `index.html`
- `css/styles.css`
- `js/app.js`
- `components/student-01.html`
- `components/student-02.html`
- `components/student-03.html`
- `components/student-04.html`
- `components/student-05.html`
- `components/student-06.html`
- `components/student-07.html`

## Reglas de colaboracion
- Cada estudiante debe modificar unicamente su propio archivo de componente.
- Los cambios se realizan en rama, se envian por pull request, se validan y luego se integran.

## Ejecucion local
- Abre el proyecto con Live Server para que `fetch` pueda cargar los componentes HTML.

## Restricciones tecnicas
- Solo se utiliza HTML5, CSS3 y JavaScript nativo.
- No se utiliza Node.js.
- No se utiliza npm.
- No se utilizan frameworks ni librerias externas.
